# ОртоГид — учебное пособие по ортодонтии

Многостраничный статический сайт-справочник по ортодонтии для студентов
стоматологических факультетов и практикующих врачей. Оформление — в стиле
современного минимализма (светлая тема, акцентный медицинский бирюзовый цвет,
боковая навигация, плавные анимации появления).

## Структура

| Страница | Файл | Содержание |
|----------|------|------------|
| Главная | `index.html` | Обзор пособия, разделы, преимущества |
| Диагностика и классификация | `diagnostika.html` | Классификация Энгля, методы обследования, цефалометрия |
| Аппараты и техника | `apparaty.html` | Брекет-системы, съёмные и функциональные аппараты, элайнеры |
| Этапы лечения | `etapy.html` | Дорожная карта лечения от диагностики до ретенции |
| Справочник терминов | `spravochnik.html` | Глоссарий ключевых понятий |

```
.
├── index.html, diagnostika.html, apparaty.html, etapy.html, spravochnik.html
├── assets/
│   ├── css/style.css              # дизайн-система
│   ├── css/fontawesome-all.min.css
│   ├── js/main.js                 # мобильное меню + анимации
│   └── webfonts/                  # шрифты иконок
└── images/                        # иллюстрации
```

## Запуск

Сайт полностью статический — сборка не требуется. Достаточно открыть
`index.html` в браузере. Для корректной загрузки шрифтов иконок удобнее
запустить локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Технологии

- Чистые HTML5 + CSS3 (CSS-переменные, grid/flex) + ванильный JavaScript
- Иконки Font Awesome (локально)
- Структура и интерактив вдохновлены шаблоном Hyperspace (HTML5 UP)

> Материал носит образовательный характер и не заменяет клинические
> рекомендации и очную консультацию специалиста.
